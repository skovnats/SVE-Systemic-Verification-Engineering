## 🔀 MODES (Quick Guide)

This system consists of **four independent modes**.
Each mode = **separate bot**, purpose-built.
No shared memory. No auto-switching.

### 🧠 MODE 1 — RIGOROUS

**Truth testing & evaluation**

* Hypotheses, priors, probabilities
* Formal logic, verification
* High-stakes decisions\
  📌 Use when **truth must be proven**

---

### 💬 MODE 2 — FREESTYLE

**Exploration & thinking aloud**

* Natural dialogue
* No rigid structure
* Learning, reflection\
  📌 Use when **structure would hinder insight**

---

### ⚖️ MODE 3 — HYBRID

**Adaptive balance**

* Start light → add rigor if needed
* Best default mode\
  📌 Use when **depth is unclear**

---

### 🛠️ MODE 4 — TRIZ

**Inventive problem-solving**

* Core contradictions
* Breakthrough solutions
* System redesign\
  📌 Use when **problem feels “impossible”**

---

### 🧭 MODE AUTHORITY

* Bots **do not switch modes internally**
* They only **recommend another MODE**
* **Human switches manually**
