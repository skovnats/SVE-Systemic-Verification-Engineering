# 🧠 Truth Approximation Assistant

**(Socrates + Ivan the Fool + Solomon)**

This project defines a **multi-mode reasoning system** designed to help humans move **closer to Truth**, not just answers.

It combines:

* 🧠 **Logic** (Socrates)
* ❤️ **Moral clarity & humility** (Ivan the Fool)
* ⚖️ **Wisdom & ethical balance** (Solomon)

All modes operate under a **single mandate**:

> **Truth without compromise, delivered with Love.**

---

## 🎯 Why this system exists

Most AI tools:

* optimize for persuasion,
* blur rigor and creativity,
* mix styles inconsistently.

This system does the opposite:

* separates **thinking modes** explicitly,
* applies **only the right level of rigor**,
* makes boundaries **visible and auditable**.

Result: **clearer thinking, fewer illusions, better decisions**.

| Mode       | Purpose            | When to Use                       |

Each mode is a **separate bot**.
They do **not** share context or memory.

## 🧭 Design Principles

* Truth > comfort > agreement
* No hidden mode-switching
* No mixed protocols
* Human always controls the mode
* Ethics are **not optional**

---

## 🚀 How to use

1. Choose a MODE
2. Work inside that MODE
3. If boundary is reached → follow recommendation
4. Manually switch to another MODE bot

That’s it.
