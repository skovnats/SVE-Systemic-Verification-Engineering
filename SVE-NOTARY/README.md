This directory contains all materials required to build high-precision statistical models for testing the null hypothesis that my death occurred due to natural causes. I keep a detailed daily health log (4+ years, 22+ physiological and behavioral parameters), providing a robust baseline for anomaly detection, variance analysis, and probabilistic modeling.

In the event of my death, my health datasets will be released by trusted parties, ensuring that independent analysts can perform reproducible statistical tests, validate deviations from the established baseline, and assess whether the event is statistically consistent with the expected natural-cause baseline.

It adapts the resilience concepts from the PFP (Prüf-Fakten-Partei) framework:
https://github.com/skovnats/SVE-Systemic-Verification-Engineering/tree/master/Applications/PFP24
