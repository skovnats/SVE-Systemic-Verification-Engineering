If any of my conclusions are wrong — please submit a stronger explanatory model that:

* covers more verified facts,
* uses fewer assumptions,
* makes clearer falsifiable predictions.

No rhetoric. No narratives. Only models.

Protocol, data and pipeline are public.
Better model beats mine — automatically.
