## Collaboration & Consortiums

### Equal Partnership Model

**SVE allows and encourages collaboration:**

```
Any split arrangement between attorneys/firms:
├─ 50/50 (2 partners)
├─ 1/3 each (3 partners)
├─ 1/4 each (4 partners)
└─ Custom (40/30/30, 60/20/20, etc.)

Rule: Total = 100% of attorney share
Agreement: Written before filing (prevents disputes)
```

**Example calculation:**
```
Case: $50M penalty
Attorney share: 70% (trial phase) = $35M

OR negotiate based on contribution:
```

- **Better outcomes** — Specialized knowledge beats generalist approach

**Strategic benefits:**
- **Bigger targets** — Can pursue €100B cases (too large for solo firm)
- **Faster execution** — Parallel work streams
- **Stronger precedent** — Multiple jurisdictions simultaneously
- **Network effects** — SVE Family connections grow exponentially
