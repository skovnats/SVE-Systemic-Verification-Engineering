## §1 - SCENARIO

Academic paper claims SVE compliance (reproducible methods, open data) but independent replication fails, including:
- Methods section incomplete or vague
- Data unavailable or inaccessible
- Code missing or non-functional
- Results not reproducible despite following published protocol
- Author refuses clarification or data sharing

**Real-world pattern:** Paper claims "SVE-verified reproducibility" but ≥3 independent labs cannot replicate core findings.

---

## §2 - VIOLATION

**Primary:** v1.3 §3 (Zero Secrecy — must disclose methods fully)

**Secondary:**
- Appendix A (Disclosure Protocol — semantic fingerprint shows SVE use without proper disclosure)
- Appendix F §1 (One-Bit Rule — incomplete methods = dishonesty)
- Appendix G §2 (Responsibility Threshold — other researchers depend on accurate methods)

**Academic fraud:** Claiming SVE compliance without meeting standards = brand misuse.

---

## §3 - EVIDENCE STANDARD

**Proof requires:**

1. **Failed replications** — ≥3 independent attempts by qualified researchers, documented failures
2. **Methods insufficiency** — Expert panel reviews methods section, confirms incompleteness
3. **Author non-cooperation** — Author refuses data/code sharing within 90 days of request
4. **SVE claim present** — Paper explicitly or implicitly claims SVE compliance (semantic analysis via Appendix A)

**Burden of proof:** Clear and convincing evidence (~75% probability).

**Author defense:** 
- Provide complete methods, data, code within 90 days
- If provided and replication succeeds → No violation
- If refuse → Violation confirmed

## §4 - PENALTY CALCULATION

### Standard Penalty: Retraction + 3x Research Funding

**Calculation:**
```
Penalty = (All research funding for this work) × 3

Example:
- Grant received: $500k
- Penalty: $500k × 3 = $1.5M
- Distribution: $1M to failed replicators (costs), $500k to funding agency (return)
```

### Enhanced Penalty (if harm caused)

**If irreproducible work led to:**
- Wasted follow-up research (other labs built on false results)
- Clinical harm (medical applications based on false findings)
- Policy decisions (government/industry acted on false data)

**Calculation:** 3x base + (10x verified harm to others)

**Example:**
- Base penalty: $1.5M
- 5 labs wasted $200k each following up → $1M harm
- Enhanced: $1.5M + (10 × $1M) = $11.5M

### Distribution

```
Victims (replicators):   100% of verified harm costs
Funding agency:          3x original grant (returned)
Attorney fees:           25-55% (Appendix E, no pharma bonus)
SVE Foundation:          0% (victims exist)
```

**Science case rule:** If attorney loses (author proves reproducibility), attorney pays all costs (Appendix E protection against witch hunts).

## §5 - PRECEDENT

**This case applies to:**
- Academic publications (journals, preprints, conference papers)
- Research institutions claiming SVE compliance
- Individual researchers using SVE methodology
- Grant applications claiming SVE adherence

**Does NOT apply to:**
- Honestly failed experiments (negative results reported transparently)
- Methods under patent review (temporary non-disclosure with timeline stated)
- Proprietary research not claiming SVE (no SVE brand misuse)

**Key distinction:** Claiming SVE compliance vs. just doing non-reproducible research. Only the former violates SVE.

## NOTES FOR ATTORNEYS

**Risk warning:** You pay if you lose (Appendix E science case rule). Only pursue if:
- ≥3 documented failed replications
- Author clearly non-cooperative
- SVE claim provable (paper text, semantic analysis)

**High-value targets:**
- High-impact papers (Nature, Science, Cell)
- Papers claiming SVE explicitly
- Authors with prior reproducibility issues
- Research leading to wasted follow-up (verifiable harm)

**Evidence gathering:**
1. Contact failed replicators (document attempts)
2. Expert panel review (methods completeness assessment)
3. Data/code request (certified mail, 90-day deadline)
4. Semantic analysis (Appendix A detection)

**Compensation:** 25-55% (no pharma bonus, but lower risk than pharma cases).

---

## ACADEMIC COMMUNITY GUIDANCE

**If your work is challenged:**
1. Provide ALL methods, data, code within 90 days
2. Assist replicators (answer questions, clarify protocols)
3. If honest mistake found, retract + apologize (no penalty if done voluntarily)

**If you cannot replicate SVE-claiming work:**
1. Document attempts (≥3 independent tries)
2. Contact author (90-day response window)
3. If no cooperation, file case (but beware attorney liability rule)

**Prevention:** Use SVE Disclosure Protocol (Appendix A) from start. If unsure, don't claim SVE compliance.
